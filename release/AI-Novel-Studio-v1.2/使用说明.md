# 📖 AI Novel Studio 使用说明

**本地运行的 AI 小说创作软件** —— 多 Agent 协同写作（构思→执笔→审稿）、去 AI 味、长篇记忆、完全本地隐私。

---

## 🚀 三步开始使用

### 第一步：启动
双击 **`启动.bat`** → 自动启动服务并打开浏览器（首次启动约 3-5 秒）。
> 界面地址：`http://localhost:8081`（如未自动打开，手动访问即可）
> 关闭黑窗口不影响使用；停止服务请结束 `server.exe` 进程。

### 第二步：配置 AI 模型（关键！）
点右上角 **「🔑 API 密钥与模型管理」**（钥匙图标）：
1. **付费 API（推荐）**：填入你的 DeepSeek API Key（`sk-...`），点「保存」
   - 去哪申请：`https://platform.deepseek.com` → API Keys → 创建
   - 价格极低：约 ¥1/百万 tokens，写 10 万字小说约几毛钱
2. **免费网页 AI（零成本）**：切到「免费网页AI」标签 → 选豆包/DeepSeek 网页版模板 → 点「🪄 自动获取」→ 在弹出的浏览器窗口登录 → 自动抓取 Cookie
   - 注意：网页 AI 有频率限制，适合尝鲜；正式写作推荐付费 API

### 第三步：开始创作
1. 左侧 **「＋ 新建项目」** → 填书名、选类型（玄幻/校园/轻小说…）
2. 底部输入框写需求（如："第一章，少年在雨天捡到一把古剑"）→ 设目标字数 → 点 **「✨ 生成」**
3. AI 自动完成：**构思大纲 → 动笔写作 → 审稿修正**，实时流式显示

## 🛠 常用功能

| 功能 | 位置 | 说明 |
|---|---|---|
| 继续写下一章 | 底部输入「续写下一章…」 | 自动衔接前文 |
| 从光标续写 | 编辑器工具栏「✍️从光标续写」 | 从指定位置继续 |
| 去 AI 味 | 编辑器工具栏「✨去AI味」 | 检测+润色，让文风更自然 |
| 审稿/校对 | 工具箱「🔍 校对审查」 | 错别字/逻辑/设定一致性 |
| 长篇记忆 | 底部「🧠 相关记忆」 | 查看 AI 将参考的旧章节 |
| 人物卡/世界观 | 左侧导航 | 设定角色与世界观，AI 自动参考 |
| 版本历史 | 工具栏「📜 版本历史」 | 保存/回退任意版本 |
| 主题切换 | 顶栏「🌙 主题」 | 6 套主题自由换 |

## ⚙️ 高级

- **创作模式**：顶栏下拉可选「智能协同（推荐）/快速草稿/严谨模式/文艺创作/指派Agent模型」等 8 种
- **思考开关**：默认仅规划师开思考（快）；「🧠 思考·全开」= 全部角色深度思考（更稳但慢）
- **批量建章**：底部「⚙️ 选项」→「📋 批量建章」，按大纲一次建多章
- **数据备份**：数据存在 `data/` 目录，自动每日备份到 `data/backups/`

## ❓ 常见问题

**Q：生成很慢？**
A：标准模式（构思+写作+审稿）300 字约 30-50 秒属正常。要快用「快速草稿」模式。

**Q：字数不对？**
A：目标 1000 字会生成 870-1000 字（±15% 内），超长会自动裁剪。

**Q：想卸载？**
A：删除整个文件夹即可（数据在 `data/`，需要保留请先复制）。

**Q：端口 8081 被占用？**
A：修改 `configs/config.yaml` 中 `server.port`，然后重启。

AI辅助写作助手 新手操作指南

多模型角色调度 AI 写作协作平台 · 5 分钟上手

一、首次启动：配置 API Key

1

获取 API Key
前往 platform.deepseek.com 注册账号（推荐，性价比最高）， 在「API Keys」页面创建一个新 Key，复制 sk- 开头的字符串。
其他厂商同样适用：Kimi（moonshot.cn）、OpenAI 等。

2

运行配置向导
双击 setup.bat（或首次运行 run.bat 时会自动弹出）。 按提示选择模型、填入 API Key，向导会自动生成配置文件。

3

启动应用
双击 run.bat，浏览器会自动打开 http://localhost:8081。

💡 提示：所有数据存储在本地 data/ 目录，不会上传。API Key 可随时在应用内「模型设置」面板修改，或双击 setup.bat 重新配置。

二、界面速览

区域功能
顶部状态栏今日用量（调用次数/Token）、主题切换
左侧栏项目列表、当前项目的资源树（稿件版本/人物卡/世界观/素材）
中央编辑区双模式编辑器（富文本/Markdown）+ 底部创作指令输入
右侧面板流水线进度、模板库、设定资源勾选、工具集

三、四步开始写作

1

点击「＋ 新建项目」，输入小说名称和类型

2

在底部输入框写下创作需求，例如：
"续写第 3 章：主角在拍卖会上拍到一把神秘古剑，散场后被人跟踪，展开追逐战"

3

设置目标字数（推荐 1000-2000 字），选择创作模式（默认「智能协同」即可），点击「✨ 生成」

4

等待流水线跑完，正文会自动追加到编辑器。不满意可选中文字用悬浮工具栏重新处理。

💡 你写一部分我再续写：直接在编辑器里写好开头，选中文字 → 使用弹出的悬浮工具栏（续写/扩写等），AI 会基于你的内容继续。

四、创作模式说明

模式适用场景流水线
智能协同常规创作，自动判定Thinker 大纲 → Worker 撰写 → Verifier 校验
严谨模式学术/正式/逻辑严密Thinker 初稿 → Worker 润色 → Verifier 严审
文艺创作文笔优先、叙事自由Thinker 极简框架 → Worker 自由写 → Verifier 宽松审
轻量快速缩写/扩写/改写/摘要直接调用 Helper，快速返回
手动自选指定具体模型跳过流水线，直调选定模型

五、选中文字快捷工具

在编辑器中选中一段文字后，会弹出悬浮工具栏：

按钮功能
扩写增加细节描写，保留核心剧情
缩写精简冗余，保留全部关键信息
改写文风弹出文风输入框，如"武侠古风"
润色修正语病，优化语句通顺度
续写承接选中文字继续向后写
摘要生成选中文字的简短摘要
调整氛围弹出氛围输入框，如"压抑沉重"

六、设定系统使用技巧

先写再补设定（推荐新手）

在编辑器里写几章内容 → 点击侧栏人物卡区域或编辑器工具栏的 🤖 AI 总结 按钮 → AI 自动从正文中提取所有人物和世界观 → 弹窗勾选需要的条目保存。

先建设定再写

在左侧资源树中点击 ＋ 手动创建人物卡和世界观 → 在右侧面板勾选需要 AI 参考的资源 → 勾选的设定会自动注入生成请求，确保角色不 OOC、世界观统一。

七、快捷键

Ctrl + Enter发送生成请求
Ctrl + S保存当前稿件为版本
Escape终止生成 / 关闭弹窗
?弹出快捷键面板
Ctrl + Shift + P进入专注模式

八、常见问题

Q：生成按钮是灰色的？
A：检查顶部状态栏用量是否已满。每天默认 500 次调用/200 万 Token，足够使用。
Q：生成的文字不符合预期？
A：① 在右侧面板勾选相关人物卡和世界观，提供更多上下文；② 在指令框中写清楚具体要求（风格、长度、避免的内容）；③ 使用版本历史回退后重试。
Q：出现"模型调用失败"？
A：检查 API Key 是否有效、账户是否有余额。系统会自动切换备用模型，全部失败才会报错。
Q：如何备份数据？
A：整个项目数据存储在 data/ai-novel.db（SQLite），直接复制该文件即可备份。同时编辑器每 30 秒自动保存草稿到浏览器缓存。

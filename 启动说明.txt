一、快速启动（推荐）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. 进入本项目文件夹（ai-novel-main）
2. 双击「一键启动.bat」
   （首次使用会自动弹出 API Key 配置向导）
3. 稍等 3-5 秒，浏览器会自动打开写作界面
4. 界面地址：http://localhost:8081/

二、使用 PowerShell 脚本启动（进阶）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

如果「一键启动.bat」无法正常使用，可以用 PowerShell 脚本：

1. 在项目文件夹内，按住 Shift 键点击鼠标右键
2. 选择"在此处打开 PowerShell 窗口"
3. 输入以下命令执行（二选一）：

   完整启动（含环境检查 + 公网隧道）：
   .\start_all.ps1

   仅本地启动（跳过 cpolar 公网隧道）：
   .\start_all.ps1 -NoCpolar

4. 脚本会自动检测 Go 环境、检查项目文件、启动服务
5. 如果 cpolar 安装了，会自动提取公网地址并复制到剪贴板

五、关闭服务

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Q：双击 .ps1 脚本报错"无法加载文件…在此系统上禁止运行脚本"
A：这是 Windows 的默认安全限制。解决方法：
   1. 右键点击"开始"菜单 → 选择"Windows PowerShell(管理员)"
   2. 输入以下命令，按 Enter 执行：
      Set-ExecutionPolicy RemoteSigned
   3. 输入 Y 确认（即"是"）
   4. 关闭管理员窗口，再重新双击本脚本即可

Q：浏览器打开后页面空白或报错
A：等待 Go 后端完全启动（命令行窗口出现日志后再刷新页面）
   如果长时间无响应，检查 configs/config.yaml 中的 API Key 是否正确

Q：端口 8081 被占用
A：脚本会自动释放端口。如果释放失败：
   1. 运行 stop_all.ps1
   2. 检查是否有其他程序占用 8081 端口（如已经运行的旧版本）

Q：如何让外网朋友访问我的写作平台？
A：安装 cpolar（www.cpolar.com），将 cpolar.exe 放入项目文件夹
   启动脚本会自动建立隧道，并在控制台显示公网 HTTPS 地址
   注意：公网访问建议先设置密码（修改 configs/config.yaml 中的 auth_password）

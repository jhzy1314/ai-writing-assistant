一、如何启动
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

方法一（推荐）— 双击一键启动：
  1. 双击「一键启动.bat」
  2. 首次使用会弹出 API Key 配置向导，按提示填入即可
  3. 等待几秒，浏览器自动打开写作界面

方法二 — PowerShell 脚本启动：
  1. 进入项目文件夹（ai-novel-main）
  2. 右键 start_local.ps1 → 选择"使用 PowerShell 运行"
  3. 脚本自动检测环境，启动 Go 后端
  4. 等待终端显示"启动完成"后，浏览器自动打开

三、如何关闭
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

方法一（推荐）：
  双击 stop_all.ps1，自动关闭全部服务

方法二：
  直接关闭 Go 后端的命令行窗口

方法三：
  打开任务管理器 → 结束 go.exe 或 server.exe 进程

五、常见问题
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Q：双击 .ps1 报错"无法加载文件…禁止运行脚本"
A：Windows 默认禁止运行 PowerShell 脚本。解决方法：
  1. 右键左下角开始 → 选择"Windows PowerShell(管理员)"
  2. 输入以下命令按回车：
     Set-ExecutionPolicy RemoteSigned
  3. 输入 Y 确认
  4. 关闭窗口，重新运行脚本即可

Q：提示"Go 未安装"但明明装过了
A：重启电脑后重试。如果仍然无效：
  · 打开 cmd，输入 go version 确认 Go 能正常运行
  · 如果提示"不是内部或外部命令"，需要手动把 Go 加入 PATH
  · 默认安装路径：C:\Program Files\Go\bin

Q：启动后浏览器显示"无法访问此网站"
A：等待 Go 后端编译完成（首次编译需要 10-30 秒）
  · 观察 Go 后端窗口是否有错误日志
  · 如果端口被占用，运行 stop_all.ps1 后重试

Q：端口 8081 被其他程序占用了
A：运行 stop_all.ps1 释放端口。如果仍然占用：
  · 打开 cmd，输入：netstat -ano | findstr :8081
  · 找到占用端口的 PID，在任务管理器中结束该进程
